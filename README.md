## 通用 ESC/POS 指令
| Hex   | Ascii | ps    |
| -     | -     | -     |
| 1b 40 | ESC '@'   | 初始化 |
| 0a    | \<LF>     | 打印并换行 换行符 \n Line Feed |
| 20    | \<Space>  | 空格符 |
| 09    | \<HT>     | 制表符 \t Horizontal Tab |
| 0d    | \<CR>     | 回车符 \r Carriage Return |
| 1b 64 [n] | ESC 'd' [n]   | 打印并走纸 n 行，通常为 06 |
| 1d 56 [n] | GS 'V' [n]    | 切纸 n = 00（全切）n = 01（半切） |
| 1b 61 [n] | ESC 'a' [n]   | 对齐 n = 00（左）n = 1（中）n = 2（右） |

## 芯烨 XP-80T - 80mm热敏小票机

### 芯烨 Xtest - 应用 APP

> Xtest 连接 XP-80T 后，空闲时 Xtest 会向 XP-80T 端口 4000 发送 1b 76 00 ，XP-80T 会回复 14 00 00 00

> 自检页打印指令 1f 1b 1f 76

| Hex   | Ascii | ps    |
| -     | -     | -     |
| 1b 76 00      | ESC 'v' 00    | 端口 4000 心跳指令 |
| 1f 1b 1f 76   | 1f ESC 1f 'v' | 自检页打印指令 |
| 1d 56 42 0a   | GS 'V' 'B' 0a | 另外的半切指令 |
| 1d 56 42 01   | GS 'V' 'B' 01 | 另外的半切指令 |

